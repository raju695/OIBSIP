# Temperature Converter Website

This project is developed as **Task 3 (Level 1)** of the **Oasis Infobyte Web Development Internship**.

The Temperature Converter allows users to convert temperature values between **Celsius, Fahrenheit, and Kelvin** through a simple and interactive web interface.


## 🚀 Project Objective
To build a basic web application using **HTML, CSS, and JavaScript** that converts temperature values accurately and provides a good user experience.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript


## 🔍 Features
- Input field to enter temperature value
- Unit selection using dropdown menus
- Convert button to perform conversion
- Displays converted temperature with unit
- Supports:
  - Celsius (°C)
  - Fahrenheit (°F)
  - Kelvin (K)
- Input validation for numeric values
- Responsive and clean UI
